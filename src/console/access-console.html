API connection

The console is a plain client of the API. Everything it can do is enforced server side — signing in as a nurse and opening the Grants tab returns 403, not a hidden button.

The model

Capability (role matrix) decides what kind of action a user may ever perform. Scope (patient access grants) decides which patients they may perform it on. A request is allowed only when both agree, and every decision is written to the audit log.
